# 🛠️ DailyTools Hub

Welcome to **DailyTools Hub** – a personal productivity toolbox built to help you organize, plan, and manage your day-to-day life efficiently.

This is a modular platform where each tool is designed to address a specific daily need. From planning your tasks to managing notes or reminders, this hub is meant to be your go-to assistant.

---

## 🚀 Features

- ✨ Light/dark mode support
- 🔒 Local data storage using `localforage`
- 🔧 Modular tools (more coming soon)
- 📦 Built with React + Material UI + Styled Components

---

## 📌 Available Tools

### 🗂️ Planner

A flexible and intuitive task manager to help you stay organized throughout the day.

**Features:**
- ✅ Add, update and delete task lists
- 🧠 Each task list can have multiple tasks
- 📌 Tasks and lists are stored locally (via `localforage`)
- 🧲 Drag and Drop support for reordering both tasks and lists
- ✍️ Motivational quote generator for a little daily inspiration

```bash
# Clone the repository

# Navigate into the project folder

npm install

# Run the development server
